VOIDHARVEST — a top-down arena survival shooter. You are the last harvester
in a dead sector of the void: hold the arena against escalating waves of
shard-fiends, collect their salvage, and spend it on weapons and upgrades
between waves. Clear wave 10 and the sector is yours.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no
network request — plain Canvas 2D and WebAudio.

Controls: WASD / arrows to move, mouse to aim, hold left click to fire,
1/2/3 to switch weapons, Shift to dash, B for the upgrade shop between
waves, P or Esc to pause, M to mute, R to restart after a run ends.
